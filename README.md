One original fortune-cookie line for a software developer, written by a Python 3.13 program (standard library only, no network, deterministic) to `/output/entry.txt`:

> You will spend three hours debugging code that was never broken — only cached.

78 characters, one sentence. It reads like a fortune cookie — a short prophecy that lands in a single breath — and it says something true about a developer's day: long debugging sessions spent accusing healthy code, when the program that actually ran was a stale cached copy. The twist waits at the very end, on the word "cached", and rewards a second read.

## Run it

```sh
python3 main.py
```
